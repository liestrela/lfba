# lfba - li's own fork of Birevan's Alpha-ENV

This is a personal fork of the Minecraft a1.1.2_01 Alpha-ENV mod made by
Birevan. Birevan's mod adds among other fun things, quality of life
features for playing Minecraft a1.1.2_01.

My fork basically does very specific little (or not so) things that please
me in Minecraft. Some of the features are:
- [Chests make door sounds when opening/closing](https://github.com/liestrela/ChestSound).
- Door opening/closing sounds are not random, but instead act according to actual
    door opening/closing.
- Tools durabilities behave like on Minecraft b1.2.
- You can render the game in 720p when using the Fullscreen mode.
- Other things...

This mod isn't made for other people to play, so don't be surprised if
your game crashes suddenly sometimes.

Only patch files are available. Probably most changes in the patches are me
trying to make some sense of the unobfuscated code generated by RetroMCP.
It is possible that you have some trouble applying them directly on
RetroMCP deobfuscated code from `minecraft.jar`. Since I'm not publishing
the whole game's code here, if you need help setting things up on your
machine, you can e-mail me at estrela (at) riseup (dot) net.

You can download lfba's JAR file at <https://estrela.li/stuff/lfba/minecraft.jar>.
For installing, just use the "Replace minecraft.jar" feature from MultiMC.

No code-generation language models were used in this project.
